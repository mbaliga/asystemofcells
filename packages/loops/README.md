# @asoc/loops

The single source of truth for the loop gallery shown on `fonebrew.app/loops`.
Same shape as `@asoc/roster`: one hand-authored `loops.public.json` plus a small
loader, no build step, no fetch at runtime.

A **loop** is a Fonebrew workflow: a BPMN 2.0 graph the app's `GraphRunner`
executes. The format contract is `docs/design/bpmn-dialect.md` in the Fonebrew
repo — standard BPMN with exactly one extension point, a flat `<aarso:meta>`
element per node.

## An entry

Every field is either copied from the `.bpmn` file's own start-event provenance
(`source`, `pattern`, `distilledBy`, `distilledOn`, and the `summary`) or is
site metadata that the file does not carry (`title`, `author`, `tags`,
`accent`, `nodes`, `edges`).

```jsonc
{
  "slug": "self-critique",              // URL segment; also the .bpmn filename
  "title": "Self-critique",
  "summary": "…",                        // matches <aarso:meta summary="…">
  "pattern": "refine-loop",              // a TopologyKind key, see PATTERNS
  "author": "mbaliga",                   // who contributed the entry
  "source": "…",                         // what it was distilled from
  "distilledBy": "hand-authored",        // model that distilled it, or hand-authored
  "distilledOn": "2026-07-27",
  "nodes": 6,
  "edges": 6,
  "tags": ["reflection", "single-model"],
  "bpmnPath": "/loops/gallery/self-critique.bpmn",
  "accent": "#E4572E"
}
```

`pattern` must be one of the five `TopologyKind` keys the app itself uses —
`fan-out-aggregate`, `sample-vote`, `refine-loop`, `debate`, `pipeline` — spelled
exactly that way, because it is the same string the app stamps into the file.

## Usage

```js
import { getLoops, getLoop, groupedByPattern, patternLabel, editorUrl } from '@asoc/loops'
```

`EDITOR_PATH` and `EDITOR_LOAD_PARAM` are exported constants rather than inlined
strings, so if the web editor reads its file from a differently-named query
param, one line here fixes every link on the site.

## What is seeded

Three entries, all written by hand to demonstrate the format rather than to
reproduce any published method — that is why their `distilledBy` says
`hand-authored` and not a model name. Each was generated by replicating
`BpmnArchive.write()` and the matching `TopologyBuilder` shape exactly, then
checked for well-formedness and against the distiller's own validity rules
(unique ids, exactly one start event, at least one end event, no dangling
flows). They have **not** been opened on a phone; that is owner-verified.
