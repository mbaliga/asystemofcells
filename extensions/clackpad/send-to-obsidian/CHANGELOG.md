# Changelog

## 1.0.0

- First release: Send typed text, Send clipboard, Open vault and Connect vault from an Obsidian tab in the Tools Panel.
- Modes: new note per send, append to a daily note, append to one note. Name templates with `{{title}}`, `{{date}}`, `{{time}}`, `{{datetime}}`.
- Optional frontmatter (`created`, `source`, `tags`) on new notes.
- Original icon.
