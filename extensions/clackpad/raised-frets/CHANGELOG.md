# Changelog

## 1.1.0

- New "Look" option: "Raised plate" (the default, as before) or "Classic text". Classic text drops the plate: the predicted words are small, plain, medium-weight text sitting right on the fret line over the key of the letter that continues the word, with a faint halo so they read on any skin. Placement, tap and flick-up work the same in both looks.
- Needs Clackpad version code 50 or newer.

## 1.0.0

- First release: a `frets` suggestion surface with options for count (1 to 5), accept gesture (tap, flick up, both), placement (above the likely next letter, or evenly), keeping the suggestion strip, font size, colour and landscape.
- Original icon (a small keyboard with a word on a metal bar).
